# Stochastic approximation of semilinear parabolic equations driven by killed Lévy processes in high dimensions

This repository contains MATLAB implementations accompanying the paper *Stochastic approximation of semilinear parabolic equations driven by killed Lévy processes in high dimensions*, by Jingchao Li, Changtao Sheng, Bihao Su, and Zhi Zhou.

The programs combine forward particle simulation with a backward implicit recursion. Conditional expectations are approximated by binning particles in a low-dimensional feature space, smoothing the target sums and particle counts, and taking their ratio. The examples include a fractional problem on a unit ball, a nonhomogeneous fractional problem on a perforated domain, and a highly oscillatory Brownian problem on a cube.

The implementations use two-dimensional features. The feature grid is separate from the original physical domain, where no spatial mesh is constructed.

## Requirements

- MATLAB with support for local functions in scripts and implicit array expansion.
- Parallel Computing Toolbox when parallel execution is enabled.

Each file contains its own numerical helper functions. No external datasets or third-party numerical packages are required. The confluent hypergeometric function in the nonhomogeneous example is evaluated by a series routine included in the corresponding files.

## Files and numerical examples

Each program can be run independently. Helper functions with the same names are local to their respective files.

### Example 1: homogeneous exterior data on the unit ball

The prescribed exact solution is

$$
u(t,x)=\frac{\cos t}{1+10t^2}\bigl(1-\lVert x\rVert^2\bigr)_+^{\alpha/2},
$$

with zero exterior data and nonlinearity $\sin u+\exp(\cos u)$.

- **`frac_IBSDE_ball_homog.m`** compares numerical and exact solution profiles along $x=a(1,\ldots,1)$ for the particle numbers in `M_list`. It reports errors, exit rates, scalar-solver residuals, and elapsed time.
- **`frac_IBSDE_ball_semilinear_err_t.m`** studies time-step convergence. `N_list` specifies the time discretizations, and `M_list` contains the two particle numbers used for the comparison curves. The plot includes an $\mathcal O(\Delta t)$ reference line.
- **`frac_IBSDE_ball_semilinear_err_M.m`** studies particle-number convergence. `M_list` specifies the particle numbers, and `N_list` contains the two time discretizations used for the comparison curves. The plot includes an $\mathcal O(M^{-1/2})$ reference line.

These programs use

$$
\Phi(x)=
\left(
\frac{1}{\sqrt d}\sum_{j=1}^{d}x_j,\,
\sqrt{\lVert x\rVert^2-
\left(\frac{1}{\sqrt d}\sum_{j=1}^{d}x_j\right)^2}
\right).
$$

The second coordinate is the distance from the axis generated by $(1,\ldots,1)$. The implementation clips the expression inside the square root at zero to avoid negative values caused by roundoff.

### Example 2: nonhomogeneous exterior data on a perforated domain

The domain is an ellipsoid with an interior ball removed. The prescribed exact solution is

$$
u(t,x)=e^{\cos t}x_{k_1}x_{k_2}\exp(-\lVert x\rVert^2),
\qquad k_1\ne k_2.
$$

The exterior data are given by the same expression. The nonlinearity is $\eta(\exp(\beta u)-u)$.

- **`frac_IBSDE_complex_nonhomog.m`** compares numerical and exact solution profiles along $x=a(e_{k_1}+e_{k_2})$ for the particle numbers in `M_list`. The default terminal time is `T = 50`.
- **`frac_IBSDE_complex_nonhomog_err_t.m`** computes time-step convergence curves using two particle numbers and an $\mathcal O(\Delta t)$ reference line. It saves errors, observed orders, scalar-solver residuals, timings, and numerical values.

Both programs use

$$
\Phi(x)=\bigl(x_{k_1}x_{k_2},\lVert x\rVert^2\bigr).
$$

Keep `k1` and `k2` distinct. The fractional-Laplacian formula implemented for this manufactured solution uses this condition.

### Example 3: a highly oscillatory solution on a cube

**`AC_HFO.m`** solves the Brownian case $\alpha=2$, with generator $\Delta$, on $(-L,L)^d$. It compares the numerical solution with

$$
u(t,x)=\cos(\lambda_t t)\prod_{j=1}^{d}\sin(k\pi x_j)
$$

along diagonal query points $x=a(1,\ldots,1)$.

The feature map is

$$
\Phi(x)=
\left(
\prod_{j=1}^{d}\sin(k\pi x_j),\,
\lVert x\rVert^2
\right).
$$

The first feature retains the sign and oscillations of the manufactured solution. It replaces the coordinate product $x_1x_2$ used in an earlier implementation.

The PDE is written as

$$
u_t+\Delta u+f(u)=q(t,x),
\qquad
f(u)=\cos u+\exp(\sin(u^2)).
$$

Accordingly, the BSDE source is $f(y)-q(t,x)$. The spatial forcing remains inside the fitted target.

This file is a script with local functions. Each frequency produces a separate figure. To retain the manufactured zero boundary condition when changing `L` or the frequencies, require `k*L` to be an integer for every entry of `k_list`.

## Running the programs

Download the repository and set the MATLAB current folder to the directory containing the six `.m` files. Edit the parameter block near the beginning of the desired file, then run it by name:

```matlab
% Solution comparison on the unit ball
frac_IBSDE_ball_homog

% Time-step convergence on the unit ball
frac_IBSDE_ball_semilinear_err_t

% Particle-number convergence on the unit ball
frac_IBSDE_ball_semilinear_err_M

% Solution comparison on the perforated domain
frac_IBSDE_complex_nonhomog

% Time-step convergence on the perforated domain
frac_IBSDE_complex_nonhomog_err_t

% Highly oscillatory solution on the cube
AC_HFO
```

No other experiment needs to be run first. For an initial execution check, reduce the query count, particle count, or number of parameter combinations. Use the settings for the intended experiment when generating final results.

### Parallel execution

Parallelism is across spatial query points. Each worker performs its own forward simulation and backward recursion.

**Unit-ball programs and the nonhomogeneous convergence program**

The following files attempt to start a local pool when `usePar = true`:

- `frac_IBSDE_ball_homog.m`
- `frac_IBSDE_ball_semilinear_err_t.m`
- `frac_IBSDE_ball_semilinear_err_M.m`
- `frac_IBSDE_complex_nonhomog_err_t.m`

The requested pool size is controlled by `numWorkers`. These programs include a serial fallback if the toolbox is unavailable or pool startup fails. Set `usePar = false` to select serial execution explicitly.

**Nonhomogeneous solution-profile program**

`frac_IBSDE_complex_nonhomog.m` uses an existing pool but does not create one. To run it in parallel:

```matlab
if isempty(gcp('nocreate'))
    parpool('local', 4);
end
frac_IBSDE_complex_nonhomog
```

Replace `4` with a suitable worker count. Without an existing pool, the program selects its serial loop. Set `usePar = false` when running without Parallel Computing Toolbox.

**Oscillatory cube program**

`AC_HFO.m` starts a local pool automatically when `USE_PARALLEL = true` and no pool exists. It uses at most `NUM_WORKERS` workers from the available pool.

Set

```matlab
USE_PARALLEL = false;
```

for serial execution. Unlike the other automatically parallelized programs, this script does not silently fall back to serial execution if the requested toolbox or pool is unavailable.

The seed for each query in `AC_HFO.m` is determined by `BASE_SEED`, the frequency-loop index, and the query index. It does not depend on worker scheduling.

Increasing the worker count increases memory use. Adjust it to the available memory as well as the number of CPU cores.

## Parameters and implementation details

The main settings are collected near the beginning of each file:

- `d`: physical-space dimension.
- `alpha` or `s`: fractional order, with `alpha = 2*s`. In `frac_IBSDE_complex_nonhomog.m`, change `s` because `alpha` is derived from it. The five fractional-example programs include a Brownian branch for `alpha = 2`. `AC_HFO.m` is Brownian only.
- `T`, `t0`, `N`, and `N_list`: time interval and time discretization. The time step is `(T-t0)/N`.
- `M` and `M_list`: particle count for each query point.
- `K`: number of spatial query points, not the number of feature-grid cells.
- `NBIN1`, `NBIN2`: numbers of grid entries along the two feature coordinates.
- `SMOOTHIT`: number of smoothing sweeps.
- `SOLVE_MAXIT`, `SOLVE_TOL`, `NEWTON_IT`, `NEWTON_MAXIT`, and `SCALAR_TOL`: scalar-solver settings, depending on the file.
- `nRepeats`: number of repeated runs in the convergence programs.
- `reference_height`: vertical placement of a convergence reference line. It does not change computed errors.
- `seed` or `BASE_SEED`: random-seed settings.



## Error measurements

Errors are computed against the prescribed exact solutions, not against a finer numerical reference solution.

The convergence programs use the empirical root-mean-square error over the query points:

$$
\left[
\frac{1}{K}\sum_{i=1}^{K}
\left|\widehat u(t_0,x_i)-u_{\mathrm{exact}}(t_0,x_i)\right|^2
\right]^{1/2}.
$$

When `nRepeats > 1`, the reported error combines the squared errors over the repeated runs. This is a finite-query error measure, not a numerical integration of the continuous-domain $L^2$ norm.

The unit-ball convergence programs include the prescribed exterior query points in this average. Those points have zero error because their values are assigned from the exterior data.

The $\mathcal O(\Delta t)$ and $\mathcal O(M^{-1/2})$ reference lines are slope guides. They are not computed errors or guarantees of an observed rate for every parameter choice. Time discretization, feature resolution, sampling, and scalar-solver accuracy can each affect the measured curves.

Relative errors may be large near zeros of the exact solution. Absolute errors and empirical RMS errors are more informative at those points.

## Output files

Automatic output folders are created beside the corresponding `.m` files.

| Program | Output folder | Saved formats |
| --- | --- | --- |
| `frac_IBSDE_ball_homog.m` | `output_ball_endpoint` | `.fig`, `.eps`, `.png`, `.mat` when `save_results = true` |
| `frac_IBSDE_ball_semilinear_err_t.m` | `output_ball_err_t` | `.fig`, `.eps`, `.pdf`, `.mat` |
| `frac_IBSDE_ball_semilinear_err_M.m` | `output_ball_err_M` | `.fig`, `.eps`, `.pdf`, `.mat` |
| `frac_IBSDE_complex_nonhomog_err_t.m` | `output_complex_err_t` | `.fig`, `.eps`, `.pdf`, `.mat` |
| `frac_IBSDE_complex_nonhomog.m` | No automatic export enabled | Displays the figure. Uncomment the save block to export `.fig`, `.eps`, and `.mat` files. |
| `AC_HFO.m` | `AC_HFO_results` | `.fig`, `.eps`, `.pdf` when `SAVE_FIGURES = true` |

The three convergence programs save a `.mat` checkpoint after each completed `(N,M)` pair. The saved data include errors, observed orders, numerical and exact values, timings, solver residuals, and parameter settings.



For example, the default run with `k = 3` produces `HFO2000_64000_11_3` in each of these formats. The script does not currently export a `.mat` file automatically.
